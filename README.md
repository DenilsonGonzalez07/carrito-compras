# Carrito de Compras Web

## Propósito
Este proyecto es una aplicación web interactiva que simula un carrito de compras. Permite agregar productos, modificar cantidades, eliminarlos y calcular el total de la compra aplicando descuentos.

## Tecnologías utilizadas
* HTML5
* CSS3
* JavaScript (Vanilla)

## Instrucciones para ejecutar
1. Clona este repositorio en tu computadora.
2. Abre el archivo `carrito.html` en cualquier navegador web.
3. No se requiere instalación de dependencias ni servidores locales.
